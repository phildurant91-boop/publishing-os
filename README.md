
# Publishing OS

Publishing OS is a modular AI-powered publishing system built with n8n.

The goal of this project is to automate the research, planning, writing, editing, quality assurance, formatting, publishing, and marketing of high-quality nonfiction books.

## Objectives

- Produce commercially viable nonfiction books
- Create reusable AI agents
- Build modular n8n workflows
- Maintain consistent quality through shared templates and standards
- Package the system for reuse and eventual sale

## Phase 1

- Project Manager
- Market Research
- Book Planner
- Research Agent
- Chapter Brief Agent
- Writing Agent
- Editing Agent
- QA Agent
- Publishing Metadata Agent
